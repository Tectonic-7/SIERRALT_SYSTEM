# SIERRALT SYSTEM

## Disaster Alert System for Sierra Leone

### Project Description

SIERRALT is a Digital Public Good designed to improve disaster preparedness, communication, and emergency response within Sierra Leone.

The platform enables citizens to receive real-time disaster alerts, report hazards, access emergency information, locate shelters, and receive weather-related warnings.

The system integrates citizens, the National Disaster Management Agency (NDMA), and the Meteorological Service (MET Service) into a centralized disaster management platform.

### Objectives

* Provide real-time disaster alerts
* Improve communication between citizens and authorities
* Support hazard reporting
* Enhance emergency response coordination
* Promote climate resilience
